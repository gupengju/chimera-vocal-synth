# 这是贵阳话前端唯一的规则来源。crates/chimera/src/phonetics/guiyang_rules.rs 解析它；
# 浏览器（Vite 把 public/ 挂在根路径）和 CLI（从仓库根读同一路径）都在运行时加载，
# 改完不用重编译就能听。crates 里另嵌了一份同样的文本（include_str!）当保底，
# 所以这个文件坏了不能让构建失败——但改错了会在加载时报出行号。
#
# 语法：
#   # 注释            [section] 分节            一行 = 空白分隔的字段
#   音素直接写 IPA 字符；一个韵母展开成两段（韵核 + 韵尾）时用空格隔开。
#
# 音系约定（改之前先读）：
#   * b d g 是不送气 [p t k]，p t k 送气[p t k]；z c s 是齿龈 [ts tsʰ s]（不是普通话的舌尖前）；
#     r 是 [z]；j q x 是 [tɕ tɕʰ ɕ]；h 是 [x]。
#   * e 是 [ɛ]，o 是 [o]（没有 [w] 介音），ong 是 [oŋ]；iu 是 [iəu]，iw 是方言的 [iu]。
#   * ng 是真正的 ŋ 声母（安 ngan¹ = [ŋan]），裸韵母才是零声母（爱 ngai⁴ 与 ai⁴ 对立）。
#     ŋ 与 m/n/p/t 同级，是独立辅音音段；它不使后面的元音鼻化（鼻化是韵母层的事）。
#   * 声调 55/21/42/13，见 [tones]；planner 的 ToneScheme::Guiyang 用同一组调值。

[tones]
# 调号（记法里的数字）→ 调值（赵元任五度制）。每级 = 多少半音见 [melody] 的 chaostep，
# 3 级 = 说话人的基准音高。数字写几个，就把这段韵母按时间均分成几个音高点：
#   两个点 = 前半段一个高度、后半段另一个高度（平调 / 平降 / 平升）；
#   三个点 = 先降到那里再挑起来（普通话上声单念 214 就是这种）。
# 这里的调值会直接变成 f0 曲线，改它就能听出变化（改完刷新页面即可，不用重编）。
#   neutral  5    轻声：自己没有调值，取前字调的尾部级别（见 [melody] 的 neutral_after*）
#   1  55        阴平：高平
#   2  21        阳平：低降
#   3  42        上声：高降
#   4  13        去声：低升
